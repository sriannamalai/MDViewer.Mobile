MarkDownViewer

Go1.26+ CommonMark652/652 releasev0.1.0

A modern, embeddable Markdown viewer library for Go. Feed it Markdown, get back self-contained, themed, sanitized HTML — no CDN calls, no external assets, safe to render untrusted input by default.

⚠
v0.x — API not yet frozen
Expect additive evolution — source positions, JSON serialization — before v1.0 commits to compatibility.

Install

shell Copy 
go get github.com/sriannamalai/
  markdownviewer

652/652 CommonMark spec examples verified, plus GFM tables, footnotes, KaTeX math and mermaid — all rendered offline…
