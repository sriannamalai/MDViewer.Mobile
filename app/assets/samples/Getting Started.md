# Getting Started

MarkDownViewer reads Markdown from two kinds of vault:

1. **Samples** (this one) — bundled with the app, always here, read-only.
2. **A folder you pick** — tap "Choose folder" from the Library screen to
   grant the app persistent access to a folder of your own. That access
   survives an app restart; you'll only be asked once, unless the OS
   revokes it (in which case you'll be asked again).

## The Library screen

Files and folders are listed alphabetically, folders first. Markdown files
are badged **M**; folders show how many Markdown files live anywhere
underneath them.

## The Reader screen

Tap any file to open it. The bottom bar shows your position in the
document and an outline of its headings — tap the outline pill to jump
around, or drag through the document itself.

## Search

The Search tab looks across every file in whichever vault is active —
filename and heading matches, plus full-text snippets with the match
highlighted.

Head back to [[Welcome]] any time, or look inside `Notes/` for two more
