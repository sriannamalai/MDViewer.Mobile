# Colophon

MarkDownViewer is built on the `mdviewer` Flutter plugin, a thin FFI layer
over the MarkDownViewer core library — the same rendering engine used by
MDViewer.Desktop. CommonMark + GFM parsing, offline KaTeX for math, offline
Mermaid for diagrams, and syntax highlighting for 250+ languages, all
sanitized by default. Nothing here ever touches the network.

Type set in IBM Plex Sans (UI), Source Serif 4 (prose headings), and
JetBrains Mono (code and metadata) — all bundled, all open source, all
licensed under the SIL Open Font License.
